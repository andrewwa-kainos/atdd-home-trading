# Home Trading

This is an ATDD sandbox project developed as part of the
[ATDD Accelerator](https://atdd-accelerator.optivem.com/) course by
[Valentina Jemuović](https://www.linkedin.com/in/valentinajemuovic/).

The intended, hypothetical, users would be individuals buying and selling
online, either as self-employment or as a side hustle.
